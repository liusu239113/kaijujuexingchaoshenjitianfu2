# 《星语奇谭 · 回廊之心》游戏策划案

> 版本 v1.0 · 竖屏单机 Roguelite 构筑 RPG · 二次元日系画风
> 目标：上架标准、可持续游玩 40 小时以上、完全离线

---

## 0. 一句话定位

在会呼吸的星语回廊里收集「星语」，让相邻的星语共鸣成链，带着一群同伴一层层往上爬——
每次倒下都会让下一次更接近回廊之心。

**核心差异点（与市面上同类爬塔 Roguelite 的区别）**：
本作不做「天赋无限叠加」，而是 **6 格星语环 + 中心神格位** 的**空间共鸣构筑**。
玩家每次觉醒都必须做「放哪一格 / 覆盖哪一个」的取舍，同源星语相邻产生共鸣链，链越长全局增益越高。
这把手气游戏变成了**摆盘游戏**，是本作最核心的辨识度。

## 2. 世界观与叙事

**回廊**：一座由故事构成的塔。每当一个故事被世人遗忘，回廊就会暗一层。
玩家是**拾语者**，带着伙伴向上攀爬，把散落的「星语」重新点亮，直到回廊之心。

- 每 10 层一位**回廊守望**（守层 NPC），给三选一的馈赠。
- 每 10 层一位**章节首领**，带专属机制。
- 图鉴里收录所有星语、伙伴、魔物的短描述（绘本式一句话文案）。

叙事呈现方式：**无过场动画**，用「守望对话 + 图鉴短句 + 结算诗」承载，成本低、气质统一。

## 3. 时长设计（为什么能玩几十小时）

| 内容层 | 数量 | 单次耗时 | 累计 |
|---|---|---|---|
| 初阶模式通关（30 层） | 1 | 2.5–4 h | 3 h |
| 进阶模式（60 层） | 1 | 5–7 h | 9 h |
| 试炼模式（100 层） | 1 | 8–12 h | 20 h |
| 霸者模式（150 层） | 1 | 12–18 h | 35 h |
| 无界模式（无限） | — | 冲榜 | 45 h+ |
| 迭塔（50 档 × 100 层） | 50 | 每档 20–40 min | 20 h+ |
| 8 职阶 × 32 转职路线 | 32 | 每种玩法差异 | 重复可玩性 |
| 星语图鉴（120+） | 120 | 收集 | 10 h+ |
| 成就（60 个） | 60 | 目标驱动 | 8 h+ |

**关键设计**：模式是**难度阶梯而非内容重复**——每个模式解锁新的敌人词缀池、新的星语、新的首领机制，
并且**神格点收益倍率递增**，让玩家自然向上挑战。迭塔则是给核心玩家的长期目标。

预计全内容时长 **45–70 小时**。

## 4. 核心循环

### 4.1 三层循环

```
[秒级] 战斗循环
  敌人意图 → 选战技 → 选目标 → 结算 → 能量/冷却管理 → 循环

[局内] 单局循环（30–60 min）
  选职阶 → 初始觉醒(星语3选1 ×3) → 爬层
     每层: 1 商店/酒肆 + N 个事件 + 1 场首领
     每 5 层: 层间觉醒（星语 3 选 1）
     第 3 层: 一转    第 30 层: 二转
     每 10 层: 守望馈赠 + 章节首领
  死亡 → 轮回结算（层数→神格点）→ 回主菜单

[长期] 元循环（小时级）
  神格点 → 轮回淬炼（永久成长树）
  星尘 → 解锁新职阶 / 新星语入池 / 图鉴
  通关 → 解锁下一难度模式 / 迭塔档位
```

### 4.2 一局的时间切片（初阶模式）
| 阶段 | 层数 | 时长 |
|---|---|---|
| 开局觉醒 | — | 1 min |
| 前期 | 1–10 | 25 min |
| 中期（一转后） | 11–20 | 35 min |
| 后期（章节首领） | 21–30 | 40 min |
| 结算 | — | 2 min |

## 5. 战斗系统

### 5.1 基本规则
- 回合制，双方轮流行动；我方单位（主角 + 最多 2 名伙伴）先手。
- 每回合开始：回能、冷却 -1、持续伤害结算、持续效果计时。
- 敌方行动前**显示意图**（攻击/群攻/控制/回复 + 目标）。
- 玩家可点选敌方卡锁定目标；单体战技优先打锁定目标。

### 5.2 属性
| 属性 | 说明 |
|---|---|
| 生命 maxHp | 归零即倒下 |
| 攻击 atk | 物理战技基数 |
| 法强 matk | 法术战技基数 |
| 防御 def | 减伤 |
| 暴击 crit / 暴伤 critDmg | 基础 5% / 50% |
| 闪避 dodge | 上限 75% |
| 回能 energyRegen | 每回合能量 |
| 吸血 lifesteal | 上限 60% |
| 增伤 dmgBonus / 减伤 dmgReduction | 乘区 |
| 破甲 armorPen | 上限 90% |
| 状态抗性 statusRes | 抵抗概率 = res/(100+res) |

### 5.3 伤害公式（权威）
```
有效防御 D = target.def × (1 - 破甲层数×5%) × (1 - armorPen)
基础伤害   = 战技基数² / (战技基数 + D × 1.2) × 战技系数 × 命中段数
乘区       = (1 + 增伤) / (1 + 减伤)        [下限 0.1]
回合递增   = 1 + max(0, 回合数 - 10) × 1%
暴击       = × (1 + 暴伤/100)
最终       = max(1, 上述乘积)
```
> 回合上限 500；到顶按胜利结算，奖励 ×0.5。第 10 回合起每回合 +1% 伤害，逼迫双方速战。

### 5.4 战技与能量
- 每位单位最多装备 **6 个战技**（普攻固定占 1 位）。
- 普攻：0 耗能，命中后回 20 能量。
- 战技：耗能 16–30，冷却 2–4 回合。
- 终极技：耗能 45–50，冷却 6 回合，每职阶/转职各 1 个。
- 能量上限 100，每回合自然回能 12–20（依职阶）。

### 5.5 状态效果（22 种）
灼烧 / 中毒 / 眩晕 / 沉默 / 破甲 / 被追猎 / 虚弱 / 强化 / 坚韧 / 闪避 / 再生 /
护盾 / 反击 / 嘲讽 / 荆棘 / 免控 / 铁壁 / 血沸 / 汲血 / 疾风 / 免死 / 首领再生

## 6. 星语环（核心差异化系统）

### 6.1 规则
- 星语环 = **6 个环形槽位** + **中心神格位**。
- 每次觉醒从 3（或 4）个候选星语中选 1。
- **环满后必须覆盖一个已有槽位**——这是本作的构筑张力来源。
- 中心神格位只放**曜神级**星语，永不掉落、不可覆盖，并决定终极技形态。

### 6.2 共鸣
- 每颗星语属于 5 个源流之一：**裂界 / 磐垒 / 星轨 / 滋育 / 命途**。
- 相邻两格同源 → 结成 1 条**共鸣边**。
- 全局增益：
  - 增伤 +6% × 共鸣边数
  - 生命 +5% × 共鸣边数
  - 防御 +4% × 共鸣边数
  - 回能 +1 × 共鸣边数
  - 最长链 ≥3 额外 +5% 增伤/链长
- 共鸣称号：单链 / 双链 / 三相共鸣（3边）/ 四方共鸣（4连）/ 神格回环（5连）

### 6.3 稀有度与投放
| 稀有度 | 星级 | 基础权重 |
|---|---|---|
| 凡庸 | ★ | 38 |
| 精巧 | ★★ | 25 |
| 灿烂 | ★★★ | 14 |
| 辉耀 | ★★★★ | 7 |
| 神话 | ★★★★★ | 3 |
| 曜神级 | ★（神格位专用） | 开局必得 |

- **保底**：连续未出神话则神话权重 +60（阈值 15 抽，可被「保底推进」永久成长降低到 6）。
- **升星**：消耗神格点，1★→2★→3★，效果 ×1.5 / ×2.0。

| 阶段 | 解锁 | 内容 |
|---|---|---|
| 一转 | 第 3 层 | 每职阶 2 条路线，二选一，+2 专属战技 + 属性加成 |

## 10. 事件与商店

### 10.1 楼层结构
```
每层 = 1 个固定设施（奇数层酒肆 / 偶数层商店）
     + K 个随机遭遇（K = clamp(6 + (层-1)/5, 6, 10) - 2）
     + (层 % 10 == 0 ? 1 个守望剧情 : 0)
     + 1 个层末首领
```
- 精锐遭遇概率 = min(50%, 10% + 层×2%)
- 同类遭遇不连续出现超过 2 次

### 10.2 事件池（45 个）
训练 / 神龛 / 泉 / 赌局 / 篝火 / 书库 / 医帐 / 通缉 / 符文匠 / 星轨商人 / 宝库 / 古战场 /
曜金锻炉 / 神格残晶 / 永存王座 / 时序裂隙 / 朝圣 / 月井 / 弃置兵架 / 先知 / 竞技场 /
魂火熔炉 / 贤者 / 咒印宝箱 / 星辉祭坛 / 绯血祭坛 / 游侠营地 / 机关长廊 / 余响大厅 /
炼金室 / 龙骸 / 虚渊裂隙 / 圣女泪泉 …（各 2–3 选 1）

### 10.3 商店与酒肆
- 商店：4 个随机道具，价格 30–150 金币
- 酒肆：2–3 名候选伙伴，价格 (40 + 等级×8) × 品质系数
