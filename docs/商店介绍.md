## 二、完整版介绍（适合「游戏介绍」字段）

《穿越星塔：全民登临时代》
—— 竖屏单机 · 回合制 Roguelite 构筑 RPG

【回廊会记住你】
这是一座由故事构成的塔。每当一个故事被遗忘，回廊就暗一层。
你是「拾语者」，带着同伴一层层向上攀爬，把散落的「星语」重新点亮，直到回廊之心。
21 个章节、会说话的塔——剧情用守望对话、图鉴短句与结算诗展开，安静、克制、有回响。

【摆盘，而不是叠数值：六格星语环】
本作的核心不是「天赋无限叠加」，而是 6 个环形槽位 + 1 个中心神格位的空间共鸣构筑：
· 每次觉醒，从 3~4 颗星语中选 1 颗；
· 环满之后必须覆盖掉已有的一格——放哪一格、舍哪一颗，就是这个游戏的胜负手；
· 相邻两格同源即结成「共鸣边」：增伤、生命、防御、回能全线提升，最长共鸣链还有额外加成；
· 单链 / 双链 / 三相共鸣 / 四方共鸣 / 神格回环——链越长，你越强；
· 中心神格位只放曜神级星语：开局必得、永不掉落，它决定你这局终极技的形态。
120 颗星语、5 大源流（裂界 / 磐垒 / 星轨 / 生命 / 命途）——每一局，都在重新摆一次盘。

【8 大职阶 × 32 条转职路线 × 104 个战技】
曜铁卫、星咏者、岚射手、圣歌使、夜刃、绯血裔、森语者、鸣丝使。
第 3 层一转、第 30 层二转，每条路线都有专属战技与属性走向；转职不可撤销——
它决定这一局你是谁，也决定你这一局能打出什么。

【6 档难度，最高 200 层，外加 50 档迭塔】
凡庸 50 层 → 进阶 100 层 → 试炼 150 层 → 霸者 200 层 → 无界（无止境）→ 迭塔 50 档。
难度不是内容重复：每上一档，新的敌人词缀、新的星语、新的首领机制一起解锁，神格点收益同步提升。

【12 只宠物随你出战】
火绒狐、霜羽鸟、岩甲龟、雷纹猫、翠叶鹿、星尘水母、影蝙蝠、金铃羊、毒沼蛙、晶簇兔、云朵犬、小骨龙。
宠物不是挂件：它们作为独立单位上场，能打能扛能奶，可升星培养，等级越高全队加成越高。

【装备 · 伙伴 · 事件，一局一世界】
· 装备：5 个部位 × 6 个品阶，随机词缀 + 机制词缀（双重施法 / 连击叠层 / 生命窃取 / 击杀回能 / 闪避反击…），9 套套装效果，支持一键换装与锻铸强化。
· 伙伴：招募同伴组队出战，8 种专长（锐锋 / 磐壁 / 疾行 / 星轨 / 生机 / 残虐 / 汲血 / 鹰目），可升星。
· 事件：51 个随机遭遇——神龛、赌局、炼金室、龙骸、虚渊裂隙……每一次选择都在改写这一局。

【回合制战斗，但每一步都可控】
敌方行动前显示意图，你可以点选目标锁定；普攻回能、战技耗能、终极技收尾，能量与冷却都要算。
20 余种状态与战斗效果（灼烧 / 中毒 / 眩晕 / 沉默 / 破甲 / 嘲讽 / 荆棘 / 反击 / 汲血 / 免死…），
暴击、闪避、吸血、护盾各自成流派。
懒得手动？打开「自动战斗」，随时可以接管。

【越玩越强的长期线】
· 轮回淬炼：8 个永久成长节点，死亡也能带走神格点，下一局来得更强；
· 60 项成就、星语图鉴、宠物图鉴、星尘兑换；
· 3 个存档槽，支持导出 Base64 文本，换机不丢档。

【关于本作】
· 竖屏单机，无需组队，一个人就能玩；
· 无内购，游戏内随机均为玩法随机，不存在付费随机；
· 广告为「可选激励视频」：想看就看、可领额外奖励；不看也能正常通关；
· 首次进入需完成 TapTap 登录与实名认证（防沉迷合规要求），之后即可正常游玩。

来自玩家的一句话或许更准：这不是一款手气游戏，而是一款摆盘游戏。
